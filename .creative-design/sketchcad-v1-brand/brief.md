# SketchCAD V1.0 品牌视觉三件套 — 设计 Brief

## 任务与事实

- **主题与主体**：为 SketchCAD V1.0（基于 Qt 6 的轻量级 2D CAD 设计软件，支持 GB/T 14665 制图标准，导出 JSON/DXF/STEP/DWG）创建品牌视觉三件套：竖版宣传海报、程序启动封面（Splash）、Logo。主体 = 软件品牌 SketchCAD V1.0。
- **目标与受众**：面向 CAD 工程师、机械/航空/工业设计用户。形成「专业、精准、轻量、工程可信」的第一印象。
- **产物与路线**：均为完整成品图，路线 = pure-image（不进入 HTML 排版）：
  1. 竖版海报 3:4（1536×2048）
  2. 程序启动封面 16:9（2048×1152）
  3. Logo 主图 1:1（1024×1024，彩色主标：图形标 + 字标）
- **输入与来源**：
  - 用户原文要求：①带文字 "SketchCAD V1.0"；②要有 CAD 特色；③不能有 AI 标签、水印。
  - 参考资产（仅借鉴视觉语言，不复制水印）：`resources/logo.ico`（深蓝底、浅蓝圆环 + 橙色十字准线、中心 "CAD"）；`CAD封面.jpeg`（深蓝工程网格底 + 线框齿轮/建筑 + 青蓝/橙色十字定位标线，但带 "AI生成" 与 "扣子" 水印 → 明确排除）。
- **事实边界**：
  - 准确可见文字（用户提供，唯一来源）：主标题 "SketchCAD"，版本号 "V1.0"。除这两处外不再添加任何文字（避免 AI 乱码），CAD 特色全部用图形语言表达。
  - 不虚构日期、公司、口号、域名、注册符号。
- **保留与修改**：
  - 禁止项：任何 AI 生成标签/水印/平台标识（如 "AI生成"、"扣子"）、二维码、非授权品牌名、乱码字符。
  - 决策优先级：用户锁定（文字、无AI水印、CAD特色）> 品类规则 > Agent 可裁量（具体构图、配色、材质）。

## 整体方案与逐单元内容

- **总方案**：一套视觉语言贯穿三张图 —— 深蓝工程蓝底 + 细密绘图网格 + 冷白/浅青线框几何结构 + 青蓝/橙色十字定位标线 + 微弱光边，形成「电子工程图纸 × 数字化设计」气质。三张图共享同一色彩家族与线框母题，各自承担不同版式职责。
- **视觉命题与注意力路径**：第一焦点 = "SketchCAD" 主标题（字体主视觉/字图咬合）；第二阅读层 = 网格、线框结构与十字定位标线（CAD 特色证据）；收束点 = "V1.0" 版本号。
- **共同视觉语言（生产规范）**：
  - 背景色：深海军蓝/工程深蓝（约 #0A1E3F 系），带细密等距绘图网格线（冷白/青蓝，低透明度）。
  - 线框元素：圆、同心圆、直线、多边形、齿轮啮合结构、坐标轴、尺寸标注线（箭头+数字省略）、十字定位标线（青蓝 #3EC6FF 与橙色 #FF8A3D 各一）。
  - 材质：深色哑光面板 + 细线微光边缘；整体干净、精密、无杂乱装饰。
  - 禁止：写实照片、3D 渲染噪点、红金庆典感、放射光束/镜头光晕（未授权光效）。

### 单元 1：竖版海报（3:4，1536×2048）

- 职责：宣传传播主视觉；"SketchCAD" 为绝对最大主体，字图咬合。
- 构图：上部 20%–25% 标题区放 "SketchCAD" 大标题（工程无衬线、锐利切角、白字 + 青蓝描边微光），下方 "V1.0" 版本号；中部 45%–55% 为结构型主视觉：啮合线框齿轮 + 建筑/零件线框 + 坐标轴 + 十字定位标线，与标题穿插；底部 15%–20% 信息收束区简洁（网格延续 + 一条细分割线，无文字）。四周 5%–8% 安全边距。
- 灵动动作：标题与齿轮线框局部叠压（字图咬合）。

### 单元 2：程序启动封面（16:9，2048×1152）

- 职责：Splash 屏，居中品牌展示；启动时一眼看清品牌名与版本。
- 构图：中央品牌组合 = 图形标（圆环+十字准线）在左 + "SketchCAD" 字标在右（或上下组合），"V1.0" 紧随字标下方/右侧；背景全幅深蓝网格 + 两侧淡化的线框机械结构（齿轮、建筑线框、尺寸标注线）对称分布；中央区域干净留白承载品牌组合；十字定位标线在画面四角或两侧呼应。水平方向阅读动线：左图形标 → 中字标 → V1.0。
- 灵动动作：大片留白 + 两侧线框出画。

### 单元 3：Logo 主图（1:1，1024×1024）

- 职责：程序图标/品牌标识核心图。包含图形标 + 字标 "SketchCAD"，"V1.0" 作为小字副标。
- 图形标概念：沿用现有图标语言升级 —— 深蓝圆角方形底（或纯深蓝面板），内部为 CAD 十字准线 + 圆环/罗盘刻度 + 铅笔/罗盘针式几何符号，青蓝线 + 橙色准星强调；与字标共享线宽与切角语言。
- 构图：图形标在上（约 45% 高度），字标 "SketchCAD" 在下（工程无衬线粗体），"V1.0" 更小一号置于字标下方；整体垂直居中，四周充足安全区。画面只出现品牌标识本身，无网格规范说明、无英文小字注释。
- 单色识别：设计时保证剪影在黑白下仍可识别（线宽足够、负形清晰）。

## 尺寸策略与安全区

- 海报 1536×2048（3:4）；封面 2048×1152（16:9）；Logo 1024×1024（1:1）。均为工具输出原始比例，禁止非等比拉伸。
- 关键文字与主体置于安全边距内；Logo 文字四周保留 ≥10% 安全区。

## 文字承载

- 图内一体生成文字（pure-image，随图渲染）："SketchCAD"（主标题/字标）、"V1.0"（版本号）。除此外无其他文字。
- 海报、封面、Logo 的这三处文字必须逐字核验。

## 验收规范（视觉效果）

- 三张图共享同一深蓝网格 + 线框 + 双色十字标线视觉家族；主体结构完整、比例正确。
- "SketchCAD" 拼写准确、无缺字多字；"V1.0" 准确。
- 画面无 "AI生成"、"扣子"、水印、平台标识、乱码字符。
- 每张图背景自然铺满画布，四周边距均衡，主体完整在安全边界内。
