# 法兰盘三面图参数说明

## 1. 功能入口
- **菜单**：`绘图(&D)` → `制图模板` → `法兰盘三面图...`
- **代码入口**：`src/core/FlangeViews.{h,cpp}`、`src/ui/FlangeViewsDialog.{h,cpp}`
- **测试入口**：`tests/flange_views_test.cpp`（40 断言全绿）

## 2. 几何模型
本模块生成**带颈平焊法兰（SO 型）**的三面图：
- **主视图**：圆形端面，可见外圆、中心孔、螺栓孔及分布圆；颈部外圆在背面并被盘面遮挡，按正投影不画。
- **俯视图**：轴向投影，可见外圆与颈部外圆两圈（从背面/顶面看，中心孔与螺栓孔被颈部遮挡）。
- **左视图**：轴向剖面，可见盘体厚度、颈部凸台、不可见轮廓用虚线表示。

三视图按第一角投影布置：
- **长对正**：主视图与俯视图 X 中心一致。
- **高平齐**：主视图与左视图 Y 范围/中心一致，且都等于法兰外径。
- **宽相等**：左视图宽度 = 主视图高度 = 颈部总高。

视图之间的净间距默认 12 mm（垂直方向额外加 4 mm 给尺寸标注），按图纸实际尺寸恒定，不随比例缩放，从而保证打印出来的三面图清晰分离、互不重叠。

## 3. 可调参数

| 参数名 | 字段 | 默认值 | 范围 | 说明 |
|--------|------|--------|------|------|
| 法兰外径 D | `outerD` | 210.0 mm | 20 ~ 5000 | 法兰盘最大外径 |
| 颈部外径 N | `hubD` | 150.0 mm | 5 ~ 2000 | 凸台/短颈外径 |
| 法兰厚度 C | `thickness` | 16.0 mm | 1 ~ 500 | 盘体厚度 |
| 中心孔径 | `boreD` | 110.0 mm | 1 ~ 1500 | 中心通孔直径 |
| 螺栓孔分布圆直径 K | `boltCircle` | 170.0 mm | 1 ~ 3000 | 螺栓孔中心圆直径 |
| 螺栓孔径 L | `boltHoleD` | 18.0 mm | 1 ~ 200 | 单个螺栓通孔直径 |
| 螺栓孔数量 n | `boltCount` | 4 | 1 ~ 64 | 均布螺栓孔数 |
| 颈部总高 | `hubHeight` | 26.0 mm | 1 ~ 1000 | 盘体厚度 + 凸台高度 |
| 第一孔起始角 | `boltAngle0Deg` | 0° | -180 ~ 180 | 第一个螺栓孔的标准数学角（0° = +X） |

## 4. 结构不变式
`FlangeParams::makeValid()` 会自动把非法参数收敛到最近的合法值：
1. `hubHeight > thickness × 1.1 + 0.5`：保证凸台可见，不变成平板。
2. `boreD < hubD`：保证颈部有正壁厚。
3. `boltCircle/2 ∈ [boreD/2 + boltHoleD/2 + 0.5, outerD/2 − boltHoleD/2 − 0.5]`：螺栓孔完整落在中心孔与外缘之间的环带内。
4. `boltCount ∈ [1, 64]`。

## 5. 自动比例与 A4 布局
- `autoScale = true` 时，模块自动在 GB/T 14690 标准比例序列 `50:1 … 1:100` 中选取能放入 A4 可用区的最大比例。
- 三视图布置在扣除图框边距与标题栏后的可用区内，自动居中。
- 中心线如超出图框会被自动裁剪到图框边界，避免小规格法兰时顶出图框。

## 6. 图层约定
| 图层名 | 线型 | 用途 |
|--------|------|------|
| `法兰-轮廓` | 粗实线 | 可见轮廓 |
| `法兰-虚线` | 细虚线 | 不可见轮廓 |
| `法兰-中心线` | 点划线 | 轴线、中心圆 |
| `法兰-标注` | 细实线 | 尺寸标注与引线 |
| `法兰-文字` | 细实线 | 视图名与说明 |

## 7. 关键文件
- `src/core/FlangeViews.h`：参数结构、结果结构、生成函数声明。
- `src/core/FlangeViews.cpp`：参数收敛、布局、三视图与标注生成。
- `src/ui/FlangeViewsDialog.cpp`：参数对话框与模型写入。
- `tests/flange_views_test.cpp`：40 例回归测试（结构/投影/参数敏感性/不变式/图面合规/渲染预览）。

## 8. 渲染预览
测试运行后会写出三张 PNG 到 `build/flange_preview/`：
- `flange_dn100.png`：默认 DN100，四孔。
- `flange_dn300.png`：DN300 规格，八孔。
- `flange_dn900.png`：DN900 大规格，多孔，自动 1:20 比例。
