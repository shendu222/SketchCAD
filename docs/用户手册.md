## 1. 程序简介

**SketchCAD** 是一款面向工程制图的二维 CAD 草图工具，最初为航空 CAD 草图模块而构建，现已覆盖通用机械与建筑装修制图。其设计目标是：

- **符合国标**：线宽组别、线型、图框、尺寸注法、剖面、粗糙度等均遵循 GB/T 系列标准；同时支持向 ISO 标准切换。
- **交互与脚本并存**：既可通过菜单、工具栏、鼠标在画布上直接绘制，也可通过底部**命令行**输入指令精确绘图。
- **参数化模板**：内置多个「制图模板」，给定一组参数即可自动生成三视图、剖面、标注、图签等成套图面。
- **纯 Qt Widgets，零外部几何库**：DXF / STEP 读写、剖面填充、约束求解均为自研实现，依赖最少。

核心数据模型为统一的图元（`Element`）列表，包含直线、圆、圆弧、矩形、多边形、样条、椭圆、折线、文本、尺寸标注、剖面区域等 12 类。

## 2. 环境要求

> 当前构建脚本（`build.sh`）把 Qt、MinGW、CMake、Ninja 的**绝对路径写死**在 `C:/Qt/...` 下。若您的安装路径不同，需相应修改 `CMakeLists.txt` 与 `build.sh` 中的路径。

| 类别 | 要求 | 说明 |
|---|---|---|
| **操作系统** | Windows 10 / 11（64 位） | 已验证于 Windows 11 Home |
| **编译器** | MinGW-w64 **GCC 13.1.0** | 由 Qt 自带（`C:/Qt/Tools/mingw1310_64/bin`）。注意 mingw_64 构建需匹配的 `mingw1310` ABI |
| **Qt 框架** | **Qt 6.10.1**（`mingw_64` 构建） | 仅需 `Widgets` 模块（`find_package(Qt6 REQUIRED COMPONENTS Widgets)`） |
| **构建系统** | **CMake ≥ 3.16** | 生成器固定为 Ninja |
| **构建工具** | **Ninja** | `C:/Qt/Tools/Ninja/ninja.exe` |
| **Shell** | Git Bash（推荐）或 PowerShell | 运行 `build.sh` 与可执行文件 |
| **C++ 标准** | **C++17** | 由 `CMAKE_CXX_STANDARD 17` 强制 |
| **第三方库** | 无 | 仅 Qt 运行时；DXF/STEP/几何算法均为自研 |

> 说明：程序**不含**任何外部几何/渲染库（无 ODA、无 OpenCASCADE、无 LibreDWG）。DWG 采用**自研的原生 R12 (AC1009) 二进制读写**（见 §6 文件格式）。

## 3. 安装步骤

### 3.1 获取源码

```bash
git clone <仓库地址> sketch-cad-cpp
cd sketch-cad-cpp
```

### 3.2 确认工具链路径

打开 `CMakeLists.txt`（第 11–14 行）与 `build.sh`（第 11–14 行），核对以下路径与您本机一致：

| 变量 | 典型值 |
|---|---|
| `CMAKE_PREFIX_PATH`（Qt cmake） | `C:/Qt/6.10.1/mingw_64/lib/cmake` |
| `CMAKE_C_COMPILER` | `C:/Qt/Tools/mingw1310_64/bin/gcc.exe` |
| `CMAKE_CXX_COMPILER` | `C:/Qt/Tools/mingw1310_64/bin/g++.exe` |
| `QT_ROOT`（`build.sh`） | `/c/Qt/6.10.1/mingw_64` |
| `MINGW`（`build.sh`） | `/c/Qt/Tools/mingw1310_64/bin` |
| `CMAKE` / `NINJA`（`build.sh`） | `C:/Qt/Tools/CMake_64/bin/cmake.exe` / `C:/Qt/Tools/Ninja/ninja.exe` |

### 3.3 构建

在 **Git Bash** 中执行（推荐，路径处理最稳）：

```bash
./build.sh            # 增量构建 → 产物 build/SketchCAD.exe
```

其他模式：

```bash
./build.sh clean      # 清空 build/ 后完整重建
./build.sh test       # 构建并运行核心层自测 SketchSelfTest.exe
./build.sh dist       # 构建 + windeployqt 打包 → dist/SketchCAD.exe（含 Qt 运行时，可拷到无 Qt 环境运行）
```

### 3.4 运行

- 开发环境：`build/SketchCAD.exe`（需 Qt DLL 在 `PATH`，`build.sh` 已自动 `export PATH`）；
- 发布包：直接双击 `dist/SketchCAD.exe`。

> 程序**不接受命令行参数**（`main.cpp` 直接启动 GUI）。「命令行」指应用**内部**底部的命令输入框（见 §5.8），并非操作系统 argv。

## 4. 界面与整体架构

### 4.1 界面布局

启动后主窗口自上而下为：

```
┌──────────────────────────────────────────────┐
│ 菜单栏：文件(F) 编辑(E) 绘图(D) 视图(V) 帮助(H) │
├──────────────────────────────────────────────┤
│ 工具栏①（草图工具）：选择/基本图元/圆/弧/折线/…   │
│ 工具栏②（样式与视图）：删除/线宽/线型/标准/连续线 │
├──────────┬───────────────────────────┬────────┤
│ 左侧 Dock │       画布 (GraphicsView)  │ 右侧   │
│ 图层/图元 │  工作平面·网格·坐标轴·图元   │ Dock   │
│ /属性面板 │                            │ 属性/  │
│          │                            │ 图元/  │
│          │                            │ BOM    │
├──────────┴───────────────────────────┴────────┤
│ 状态栏             │ 命令行（CommandInterpreter） │
└──────────────────────────────────────────────┘
```

- **画布**：显示工作平面、网格、坐标轴与所有图元；右键拖拽平移、滚轮缩放。
- **左侧 Dock**：可切换图层面板、图元面板、属性面板、BOM、日志、命令行等（视图 › 面板）。
- **底部命令行**：输入文本命令精确绘图。

### 4.2 软件架构（分层）

| 层 | 主要类 | 职责 |
|---|---|---|
| **入口** | `main.cpp` → `MainWindow` | 构建主窗口、进入 Qt 事件循环 |
| **UI 层** | `MainWindow`、`GraphicsView`、`ElementItem`、`ModelMediator`、`*Panel`、`*Dialog`、`tools/*` | 菜单/工具栏/面板/画布交互/绘制工具策略 |
| **核心层** | `SketchModel`、`Element`、`Geometry`、`Modify`、`Section`、`Commands`、`ConstraintSolver`、`CadFormats`、`*Views`（模板） | 纯几何与数据计算，不依赖 Qt Widgets |
| **交互中介** | `ModelMediator`、`ToolRegistry`、`CommandInterpreter` | 解耦模型/视图/面板/命令行 |

**数据模型**：所有图元存于 `SketchModel.elems_`（`std::vector<Element>`，自增 `nextId_`）。坐标用世界坐标（X 右、Y 上），视图层做 Y 翻转映射到屏幕。选中集由 `selectedId_`（单选）与 `selectedIds_`（多选）维护。撤销/重做通过 `undoStack_/redoStack_`（`Memento` 含图元+ID+比例+图层）实现。

### 5.4 绘图（绘图(&D)）

#### 5.4.1 直线(&L)
基本：两点线 `line`、水平线 `line_h`、竖直线 `line_v`、角度线 `line_angle`、平行线 `line_parallel`、角平分线 `line_bisector`；
切线：过圆/圆/点作切线（`line_tangent_pc/cc/t2e1p` 等）；
正交折线：`line_snake`（自由正交折返）、`line_snake_x/y`（先横后纵 / 先纵后横）。

#### 5.4.2 圆(&C)
`circle`（圆心+半径）、`circle_2p`（两点直径）、`circle_3p`（三点）、`circle_cr`（圆心+过点）；相切圆（`circle_t2e1p` 等）；内切圆 `circle_inscribed`、同心圆 `circle_concentric`、由圆弧得圆 `circle_byarc`。

#### 5.4.3 圆弧(&A)
`arc`（圆心+起止角）、`arc_3p`（三点）、`arc_cpc`（圆心+两过点）、`arc_tpa`（切线+点+角）等；相切弧 `arc_tan`；椭圆弧 `arc_ea_axis/_1pt`。

#### 5.4.4 多边形(&P)
`poly`（自由多边形）、`rect`（矩形）、正多边形 `poly_regular/_circumscribed/_edge`、倒角/圆角矩形 `rect_chamfer/_fillet`、星形 `poly_star`。

#### 5.4.5 样条(&S)
抛物线 `spline_parabola*`、双曲线 `spline_hyperbola`、通用 `spline` / `spline_through_points` / `spline_from_polyline`；编辑：`spline_append_pt`（追加点）、`spline_insert_pts`（插入点）、`spline_remove_pts`、`spline_explode`（炸开）；手绘 `freehand_line`。

#### 5.4.6 椭圆(&E)
`ellipse_1pt`（中心+轴端点）、`ellipse_axis`（轴）、`ellipse_foci`（焦点）、`ellipse_4p`、`ellipse_c3p`（三点）、`ellipse_inscribed`（内切）。

#### 5.4.7 折线(&Y)
`polyline`；节点编辑：`polyline_add_node` / `append_node` / `delete_node` / `delete_between` / `trim_segments`；`polyline_equidistant`（等距偏移）、`polyline_from_segments`、`polyline_arcs_to_chords`（弧转弦）、`polyline_change_segment_type`（段类型切换：直/弧）。

#### 5.4.8 绘制选项
- **连续直线**（快捷键 `K`）：开启后连续画线自动首尾相接。
- **线宽**：`1 / 2 / 3 / 5 px` 子菜单，按当前线宽组别区分粗细。
- **颜色**：含「自定义颜色…」。
- **约束工具**（快捷键 `N`）：重合、平行、垂直、相等、相切、水平、竖直、固定。施加后关联图元参数自动联动。

| 标注 | 快捷键 | 说明 |

| 水平 `dim_h` | — | 仅水平投影尺寸 |
| 竖直 `dim_v` | — | 仅竖直投影尺寸 |
| 角度 `dim_angle` | `Shift+A` | 两线夹角 |
| 半径 `dim_radius` | `Shift+R` | 圆弧半径 |
| 直径 `dim_diameter` | `Shift+I` | 圆/圆弧直径 |
| 基线 `dim_baseline` | — | 共用基准的串联标注 |
| 连续 `dim_continue` | — | 首尾相接的连续标注 |
| 弧长 `dim_arc` | — | 弧长标注 |
| 引线 `dim_leader` | — | 指向说明文字的引线 |

标注样式（箭头形式、文字方向、公差样式）可通过「标准切换」在 GB/T 与 ISO 间切换，详见 §6。

### 5.7 制图模板（绘图 › 制图模板）

各模板均为「对话框驱动」：菜单项 → 打开 `*ViewsDialog` → 填参数 → 自动生成图元并加入图纸。下列参数为各 `Params` 结构的核心字段默认值。

#### (1) 飞机三面图…
- 生成：正面/侧面/俯视三视图（直线、圆、弧、椭圆、标注、文字）。
- 参数（单位 **米**）：机身总长 38.90、翼展 35.80、机身高 6.13、垂尾高 5.99、发动机/起落架位置等。

#### (2) 法兰盘三面图…
- 生成：主/俯/左三视图（DN100 PN16 带颈平焊法兰：螺栓孔分布圆、中心孔、颈部凸台、尺寸标注 + 引线）。
- 参数（mm）：外径 D=210、螺栓孔圆 K=170、孔径 L=18、孔数 n=4、厚 C=16、中心孔 boreD=110、颈径 hubD=150、颈高 hubHeight=26、形态切换 hasHub / recessD / recessDepth、各类公差、图纸 A4、自动比例、标题栏避让。

#### (3) 轴承座三面图…
- 生成：主视图 + 俯视图 + **左视图全剖**（底板 + 支承板 + 圆筒，断面填 45° 剖面线，GB/T 4457.5）。
- 参数（mm）：圆筒 Ø130 / 孔 Ø96 / 台阶孔 Ø30 / 长 100、底板 240×160×20、总高 180、支承板底宽 105、U 形地脚槽 55×36、A4、自动比例。

#### (4) 箱体视图…
- 生成：主视图全剖 + A—A 断面 + 俯视图 B + C 向视图；含剖切符号（GB/T 17452）、粗糙度（GB/T 131）、技术要求文本。
- 参数（mm）：筒 Ø82 / 孔 Ø64H8、底板 46×70×7、总高 70、圆角 R3、4×M4-7H、侧凸台 Ø34/Ø26/轴高 39、壁孔 3×Ø7、A3、自动比例。

#### (5) 法兰盘轮毂视图…
- 生成：主视图全剖 A—A + 左视图圆（阶梯回转体：法兰/轮毂/沉孔/通孔/螺栓孔/定位孔，含剖面线 + 剖切符号 + 粗糙度 + 引线）。
- 参数（mm）：法兰 Ø80 / 轮毂 Ø60 / 沉孔 Ø41 / 通孔 Ø33、沉孔深 8、法兰厚 26、总长 136、倒角 C3、圆角 R4、螺栓孔 3-Ø11.5（分布圆 52）、定位孔 2-Ø10、粗糙度 roughBore/roughFace、A4、剖面线 45°/间距 3。

#### (6) 户型平面图…
- 生成：建筑装修平面图（双线墙 + 剪力墙涂黑、门开启弧/窗、家具图块、三级建筑尺寸链、引线标注、右侧装饰图签，默认 1:50）。
- 参数（mm）：外框 9200×11756、剪力墙厚 200 / 隔墙 100、门宽 900 / 卫 800 / 推拉 1500、字高、A3、自动比例 1:50，开关 showFurniture / showDims / showLabels，图签文本（公司/工程/图名等）。

> 所有模板均经 `makeValid()` 结构不变式收敛与 `validate()`：非法参数会收敛为合理几何，而非画出错误图形。

- **关于**：显示版本信息（如「航空 CAD 草图模块 v1.0 …」）。

### 5.10 外部参照（Xref）

外部参照（Xref）把**另一张图纸**的几何以「只读快照」方式带入当前图纸：**图形内容不落到本图的普通图元里**，本图只保留一条符号名为源文件主名的记录（本质上是一条特殊的块定义）与若干个参照实例。源文件后续修改**不会**自动同步到本图（重附加才会更新）。

菜单入口：**编辑(&E) › 修改(&M) › 块(&B)**（亦可在 **绘图(&D) › 块** 中找到同一子菜单）：

| 菜单项 | 说明 |
|---|---|
| **附加外部参照…** | 选择参照图形文件并指定路径类型，随即在本图原点放置一个参照实例 |
| **分离外部参照…** | 从已附加列表中选择块名，删除该参照定义及其**全部**参照实例 |

**附加时的约定**

- **支持格式**：本程序 JSON 存档、DXF、DWG（STEP 为只写格式，不接受作为参照读入）。
- **参照块名**：取源文件的文件名主名（如 `base.json` → `base`），与 AutoCAD 语义一致；若该名称已被普通块占用则拒绝附加（避免把普通块误当参照删除）。
- **插入点 / 缩放 / 旋转**：沿用默认值——插入点 `(0, 0)`、X·Y 缩放 `1.0`、旋转 `0°`；命令行可用 `xref attach <路径> [full|relative|none] [x,y] [旋转] [sx] [sy]` 覆盖。
- **路径类型**（决定「怎么写进存档」）：

| 路径类型 | 存档中记录 | 解析基准 |
|---|---|---|
| 完整路径（`full`） | 绝对路径原文 | — |
| 相对路径（`relative`） | 相对宿主页所在目录的路径 | **本图所在目录**；本图尚未存盘时退化为纯文件名 |
| 无路径（`none`） | 纯文件名 | 本图所在目录 / 搜索路径 |

- **重复附加**：同一文件已附加过会提示「已附加（如需更换请先『分离』）」并中止。
- **嵌套参照**：源文件自带的、被其引用的块定义会一并引入，标记为「嵌套参照」——**不能单独分离**，只能随直接附加它的宿主一起消失；宿主被分离且再无引用者时会被自动级联清理。

**命令行**

| 指令 | 示例 | 说明 |
|---|---|---|
| `xref list` | `xref list` | 列出本图全部外部参照（名称 / 状态 / 路径类型 / 图元数 / 记录路径） |
| `xref path` | `xref path base` | 查询某参照解析出的绝对路径 |
| `xref attach` | `xref attach D:\ref\base.json relative` | 附加；可续写路径类型、插入点与 旋转/sx/sy |
| `xref detach` | `xref detach base` | 分离（定义 + 全部实例） |

> ⚠️ 注意事项：
> 1. 参照定义在本图中**不可编辑**（如需改动图形，请改源文件后重新附加）。
> 2. 分离是**删除**操作：先把该参照的全部实例一并删掉，可以用 `undo` 一次撤销。
> 3. 若源文件被移动或改名，已附加的记录仍保留最近一次读入的几何用于显示（表现为「路径不可解」），重新加载需先分离再附加。

## 6. 标准与子系统

| 子系统 | 标准 | 关键内容 |
|---|---|---|
| 线宽组别 | GB/T 14665-2012 表1 | G1~G5，粗:细 = 2:1；默认 **G3**（粗 1.0 / 细 0.5 mm）。进程内可切换当前组 |
| 线型 | GB/T 4457.4 → 14665 4.1 | 9 种：实线/虚线/点画线/双点画线/波浪线/双折线/粗虚线/粗点画线等；含重合优先（4.3） |
| 图层 | GB/T 14665 第8章 表6 | 12 个标准层（标识号 01~12），线宽按当前线组派生 |
| 剖面 | GB/T 4457.5-2013 | 剖面材料、豁免规则（肋/轮辐/标准件/狭小区域涂黑）、45° 剖面线、相邻反向 |
| 尺寸注法 | GB/T 4458.4-2003 / ISO 129-1 | 箭头形式、文字方向、公差样式；可 GB/ISO 切换 |
| 粗糙度 | GB/T 131-2006 | 表面粗糙度符号（去除/不去除材料） |
| 剖切符号 | GB/T 17452 | A—A 等剖切位置与投射方向符号 |
| 图框/标题栏/幅面 | GB/T 14689 / 10609.1 / ISO 128 | A0~A5 幅面、第一/第三角投影、标准字高、标准比例系列 |
| 文件格式 | 自研 | JSON（原生） / DXF R12（AC1009） / STEP（ISO 10303-21 AP214 二维曲线，只写） / DWG 原生 R12（AC1009，可读可写） |

> **DWG 说明**：`toDwg()` 写出**原生 R12 (AC1009) 二进制** DWG（文件头 + 图层表 + 实体记录 + 每条记录 CRC16），可被 AutoCAD / LibreCAD / QCAD / BricsCAD 作为 `.dwg` 打开；`fromDwg()` 可读回本程序及同类 R12 文件。图元导出时炸开为 LINE / CIRCLE / ARC / TEXT / SOLID / POLYLINE+VERTEX。
>
> ⚠️ 已知限制：头变量块为占位（读者靠指针定位，不依赖其内部结构）；R12 无真彩色，颜色按 ACI 近似；文本按 UTF-8 写（R12 严格用代码页，与老版 AutoCAD 中文交换建议优先用 DXF GBK）。

## 8. 完整可复现操作示例

下面以**「从零绘制一个带尺寸标注的法兰盘草图并导出 DXF」**为例，分步演示。两种操作路径均可（GUI 点击 / 命令行），示例同时给出命令行写法，便于精确复现。

### 步骤 0：准备工作

1. 按 §3 完成构建，双击 `dist/SketchCAD.exe`（或运行 `build/SketchCAD.exe`）启动程序。
2. 进入主界面，确认左侧可见「图层」面板、底部可见「命令行」。

### 步骤 1：新建图纸

- **GUI**：菜单 `文件 › 新建`（或 `Ctrl+N`）→ 在对话框中选择幅面 **A4**、比例 **1:1**、投影角任选 → 确定。
- **结果**：画布出现 A4 图框与标题栏（自动套用 GB/T 标准图框）。

### 步骤 2：绘制法兰盘外轮廓（同心圆）

- **GUI**：`绘图 › 圆(&C) › circle（圆心+半径）` → 在画布适当位置点击确定圆心（如 `100,100`）→ 移动鼠标输入半径 `105` → 单击确认。再画一个圆心相同、半径 `55` 的圆（中心孔）。
- **命令行**（等效、可精确复现）：
  ```
  circle_cr 100,100 105
  circle_cr 100,100 55
  ```
- **结果**：两个同心圆，代表法兰外径与中心孔。

### 步骤 3：绘制螺栓孔（环形阵列）

- **GUI**：选中小圆之外的某个「螺栓孔圆」（先画一个 `circle_cr 100,100 170 半径 18` 的孔，注意 170 是半径距离）→ `编辑 › 修改 › 阵列 ▸ 环形` → 数量 `4`、总夹角 `360`、中心点 `100,100` → 确定。
- **命令行**（示意）：先画一个孔，再用环形阵列指令（具体语法以 `help` 输出为准）。
- **结果**：4 个螺栓孔均匀分布在同一分布圆上。

### 步骤 4：添加尺寸标注

- **GUI**：`绘图 › 尺寸标注 › 直径`（`Shift+I`）→ 点击外圆 → 放置标注线于圆外。同理标注中心孔与螺栓孔直径。
- **命令行**：
  ```
  dim diameter <外圆拾取>
  ```
  （标注为交互拾取，命令行主要用于直线/圆等可参数化图元；直径/半径标注建议用 GUI 点选。）
- **结果**：图面出现直径尺寸线与数值。

### 步骤 5：剖面填充（示意）

若需要剖面：画一个封闭区域（如矩形或圆）→ `编辑 › 修改 › 剖面填充`（`Ctrl+Shift+H`）→ 点击封闭区域内 → 自动填充 45° 剖面线（GB/T 4457.5）。

### 步骤 6：适配视图查看

- 按 `Ctrl+0`（适配窗口），所有图元精确充满工作区，便于检查。
- 如需放大某局部：按 `Ctrl+9`（窗口缩放）→ 拖框选中目标区域 → 释放后该区域充满工作区。

### 步骤 7：保存与导出

- **保存工程**：`文件 › 保存`（`Ctrl+S`）→ 存为 `.json`（含全部图元与样式，便于后续编辑）。
- **导出交换格式**：`文件 › 导出 DXF`（`Ctrl+E`）→ 选择路径保存为 `.dxf`，可导入其他 CAD 软件。

### 步骤 8（可选）：用参数化模板一键生成标准法兰盘三面图

- `绘图 › 制图模板 › 法兰盘三面图…` → 在对话框中确认/修改参数（D=210、K=170、L=18、n=4、C=16、boreD=110 等，默认即 DN100 PN16）→ 确定。
- 程序自动生成主/俯/左三视图 + 螺栓孔分布 + 尺寸标注 + 引线，并套用 A4 图框与标题栏，比例自动选取。
- 按 `Ctrl+0` 适配查看，按 `Ctrl+E` 导出 DXF。

> **判定成功的标准**：画布上出现同心圆 + 4 个均匀螺栓孔 + 直径标注；`Ctrl+0` 后整体充满视口且坐标轴/提示文字位置不变；导出的 DXF 能在第三方 CAD 中打开且几何一致。

## 9. 常见问题与注意事项

1. **快捷键冲突 `Ctrl+K`**：「修改 › 缩放…」与「选择 › 全部不选」共用 `Ctrl+K`。若按下无预期效果，请改用菜单项执行对应功能，或自行在 `MainWindow.cpp` 中重新分配快捷键。
2. **坐标轴无法隐藏**：坐标轴通过覆盖层常显，菜单无开关；栅格可用 `F7` 切换。两者均为屏幕常量，不随内容缩放。
3. **DWG 为原生 R12，非 R2000+**：导出的是 R12 (AC1009) 二进制 DWG，结构最简、兼容面最广，但**不含** R2000+ 的高版本特性（真彩色、UTF-8 文本、动态块等）。跨软件交换若遇编码/颜色差异，优先用 DXF（GBK）。
4. **模板参数单位不同**：飞机模板单位为**米**，其余机械模板与户型模板为 **mm**；填写参数时注意单位。
5. **构建 OOM（内存不足）**：在资源受限环境并行编译多个重型目标时可能 `cc1plus: out of memory`。对策：逐个目标编译（`ninja -C build <Target>`，或 `build.sh` 本身为增量单线），失败重跑可续编。
6. **路径写死**：`CMakeLists.txt` / `build.sh` 中 Qt、MinGW、CMake、Ninja 路径写死在 `C:/Qt/...`；换环境必须先改这两处。
7. **无 argv 命令行参数**：程序启动即 GUI；「命令行」仅指应用内底部输入框。
8. **中文与字体**：导出/保存的文本含中文时以 UTF-8 处理；若第三方工具读 DXF 出现乱码，确认其支持 GBK/UTF-8 中文编码。
