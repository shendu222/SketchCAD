## 三、剩余关键差距清单与 AI 编程提示词

> 验收基线统一为：SketchSelfTest 1224/0 不回退、`-Wall -Wextra` 零警告、双目标 `build.sh test` EXIT=0。
> 两条铁律全程有效：ElementType 枚举只增不改；存档字段语义不可重排。

### D1【高】DWG 仅 R12 —— 版本覆盖差距

**差距**：近 25 年 DWG 打不开，设计院交付通道关闭。
**修改**：合规路径前置（ODA 商业授权评审）；通过后 CadFormats 增 R2000+ 分支，与自研 R12 按版本号自动路由并存。
**提示词**：

```text
【目标】在合规授权前提下为 SketchCAD 增加 DWG R2000/R2004/R2007 读写，打开设计院交付通道。
【前置】人工完成 ODA 商业授权评审（本提示词在评审通过后执行；严禁引入 LibreDWG 等 GPL 库）。
【范围】src/core/CadFormats.cpp 增加 DWG 版本探测（头部版本串）；R2000+ 读写走 ODA 隔离层
        （新建 src/core/DwgOdaBridge.{h,cpp} 封装，禁止 ODA 头文件泄漏到 UI 层）；与现有自研
        R12 二进制读写按版本自动路由并存；版本不支持时明确报错（含版本串原文）不误读。
【约束】现有自研 R12 读写全量回归不破坏（AC1009 头部强校验语义不动）；不逆向、不内嵌任何
        逆向产物；隔离层编译为独立静态库目标并纳入 CMake。
【验收】R2000/R2004/R2007 样本读写 round-trip 黄金差分；AutoCAD 交叉打开人工核；自测新增
        ≥12 断言（版本路由/错误报文/R12 回归）；零警告；build.sh test EXIT=0。
```

### D2【高】撤销 Memento 全量快照 —— 大图内存差距

**差距**：每步全量快照×200，5 万图元内存与耗时不可接受（渲染/拾取已修，这是性能最后的洞）。
**修改**：撤销栈差量化——Modify 层已统一走 `Change + applyChanges` 单步撤销范式，把"每步全量快照"改为"变更集（受影响元素 id 的前后状态 + 新增/删除清单）"，全量快照保留为每 N 步的检查点回落。
**提示词**：

```text
【目标】撤销栈从全量 Memento 快照改为差量（变更集）存储，5 万图元场景单步撤销内存 ≤1MB、
        撤销耗时 ≤16ms，行为与现全量模式完全一致。
【范围】1) 新建 src/core/UndoDelta.{h,cpp}：DeltaRecord{新增/删除元素完整状态 + 修改元素
        (id, before, after)}，序列化复用 Element 既有编解码；2) Modify 层 applyChanges 挂钩
        生成 DeltaRecord（既有 Change 翻译层不改语义）；3) 撤销栈结构改为「每 50 步一个全量
        检查点 + 中间差量」，随机跳转步按最近检查点+回放；4) 特性开关 undoDelta（默认开，
        可回落全量模式对照）。
【约束】Element/SketchModel 序列化不动；撤销语义（单步/组合步/redo）与现行为逐字节一致；
        块/约束/标注联动撤销必须在同一步内；id 复用场景（删除后新建）重点回归。
【验收】特性开关双跑对照：随机 500 步编辑序列下两模式撤销/重做终态图元集全等；内存基准
        （5 万图元 200 步）达标；自测新增 ≥12 断言；零警告；build.sh test EXIT=0。
```

### D3【中】批量治理工具族（JOIN / ARRAY 命令行 / GROUP / 图层治理命令）

**差距**：导入离散线段无法复原多段线、阵列不可脚本化、编组与图层隔离缺失——批量效率量级差距。
**修改**：JOIN 容差连合、ARRAYRECT/POLAR/PATH 命令行、GROUP 编组表、LAYISO/LAYUNISO/LAYMCH/LTSCALE 四条高频治理命令，全部走 Modify 层既有范式。
**提示词**：

```text
【目标】补齐批量编辑与图层治理五件套：JOIN、ARRAY（矩形/环形/路径）、GROUP、LAYISO/LAYUNISO/
        LAYMCH、LTSCALE，使"导入修复→批量布置→图间组织"链路可用。
【范围】1) join：同层 Line/Arc 端点容差（复用 snap 容差与 geo::almostEqual）连合为 Polyline，
        join 后 explode 可逆；2) array：ARRAYRECT（行×列×间距）/ARRAYPOLAR（中心×数量×角度
        范围）/ARRAYPATH（沿 Polyline/Spline 等距布点），产出副本集合并入 Modify 层单步撤销，
        命令行+菜单双入口；3) group：命名编组表随图存档（JSON 容缺 key），group create/add/
        remove/list/ungroup，编组整体选中 + Ctrl 单选穿透；4) 图层治理：LAYISO（隔离当前层
        其余关闭）/LAYUNISO（恢复）/LAYMCH（目标层匹配）/LTSCALE（全局线型比例，随图存档，
        渲染链消费）；5) 命令目录 CommandCatalog 收录全部新命令（usage 取自实现「用法：」串，
        同源不编造）。
【约束】走 Change+applyChanges 单步撤销范式；ElementType 不动（新增仅限末尾追加并走八步
        清单）；QSelect/fence/WP/CP 语义不变；默认别名表既有 66 条不动，新命令可建议别名。
【验收】每命令 ≥8 断言（含退化：零间距/单元素/路径短于间距/空图层）；JOIN→explode 可逆；
        LTSCALE 0.5/2.0 虚线段长比例断言；自测新增 ≥30 断言全绿；零警告；EXIT=0。
```

### D4【中】命名标注样式管理器 + QDIM

**差距**：仅全局单 Style，一图多标准（GB+企标）不可管理；快速标注缺。
**修改**：DimStyle 多实例化（name→Style 映射随图存档）+ dimstyle 命令 + QDIM 批量标注。
**提示词**：

```text
【目标】标注样式从全局单 Style 升级为命名样式管理器，补 QDIM 快速标注，支撑一图多标准。
【范围】1) DimStyleTable（name→DimStyle 映射，随图存档，对标 blockTable 范式）；2) dimstyle
        命令族（new/rename/set/list/delete），标注图元记样式名，样式切换全图联动；3) 旧档
        （无样式表 key）读入自动生成「Standard」默认命名样式，行为向后兼容；4) qdim：框选
        一组平行线/圆阵列→一次性生成基线或连续标注（复用 dim 基线/连续引擎）；5) CommandCatalog
        收录；选项与菜单入口。
【约束】12 类既有标注与 GB/T↔ISO 切换回归不破坏；DimStyle 结构字段只增不改；标注关联
        （driverId/paramRef）随样式名迁移不丢失。
【验收】样式切换全图联动断言；旧档兼容断言；qdim 生成计数与位置断言；自测新增 ≥12 断言；
        零警告；EXIT=0。
```

### D5【中】约束求解集成（本仓库侧）—— 参数化联动差距

**差距**：本仓库仍为"改后检测-修复-传播"模型；avcad 主项目 SKT 求解器（403 测试）尚未移植，改尺寸全图联动不可用。
**修改**：移植 SKT 求解器核心（同企业内码，无许可障碍），隔离层 IConstraintSolver + 回落路径。
**提示词**：

```text
【目标】将 avcad 主项目已验证的 SKT 草图求解器（SKT-001/002/003，403 测试）集成到本仓库
        约束体系，实现"改标注值→几何全图联动"，保留现修复模型为回落。
【范围】1) 抽象层 src/core/IConstraintSolver.{h,cpp}（solve/ diagnose/ dof 接口）；2) SKT
        求解器内核以静态库目标并入 CMake（接口适配层做单位与坐标约定转换）；3) 现有显式
        约束表（Coincident/Symmetric/Dimensional/Equal/H/V/Fixed）映射为求解器约束；4) DOF
        统计与欠/过约束诊断输出到约束面板；5) 特性开关 constraintSolver（默认开，求解失败
        自动回落修复模型并日志说明）。
【约束】隐式 4 类 + 显式表既有行为全保留；存档格式不变；数值容差统一走 geo::almostEqual
        策略，禁止求解器魔数散布；ElementType 与 ConstraintRecord 结构不动。
【验收】20 个基准草图（欠/过约束/奇异构型）求解正确且诊断准确；既有约束回归全绿；改标注值
        联动断言；自测新增 ≥15 断言；零警告；EXIT=0。
```

### D6【中·发布合规】Authenticode 签名与安装包商业化收尾

**差距**：安装包已能产出，但 exe 未签名（SmartScreen 拦截告警）、Inno 免费版带 "Non-commercial" 授权提示——**商业分发的最后一公里**。
**修改**：代码签名证书接入 build.sh package 流水线；评估 Inno Setup 授权（或切换商业版/NSIS）。
**提示词**：

```text
【目标】安装包商业化收尾：Authenticode 签名接入打包流水线 + 安装器授权合规。
【范围】1) build.sh package 在 ISCC 编译后增加签名步骤（signtool sign /fd SHA256 /tr 时间戳
        服务器，证书路径与口令走环境变量 PKG_CERT/PKG_CERT_PWD，缺失则跳过并醒目告警"产物
        未签名"）；2) 对 Setup.exe 与包内 SketchCAD.exe 双签名；3) 校验和文件纳入签名后哈希；
        4) 输出 Inno Setup 授权评估说明（免费版 Non-commercial 提示 vs 商业 license 或 NSIS
        备选），供人工决策。
【约束】签名失败不得产出静默无签名的"看起来成功"包（告警必须可见）；不把证书口令写入
        任何脚本/仓库文件；现有版本号单一来源与校验和逻辑不动。
【验收】双签名产物 signtool verify /pa 通过；无证书环境跑流水线得到明确告警且包体正常；
        checksums.sha256 与签名后文件一致；build.sh package 全程 EXIT=0。
```

### D7【低】文字字段 FIELD + 表格公式

**差距**：MText/Table 无域与公式，明细栏数量/面积手动维护。
**提示词**：

```text
【目标】MText 支持 FIELD 域（面积/图元计数/自定义特性）、Table 支持简单公式列，明细栏自动
        维护。
【范围】1) Field 图元内嵌标记（{field:area:<id>} 等），渲染期解析求值（复用 Inquiry 层
        massprop/计数 API）；2) 上游几何变更→域失效重算（挂 applyChanges 钩子）；3) Table
        单元格支持 =sum/=count 简单公式（引用行号）；4) 域更新 fieldupdate 命令 + 打开文档
        时自动刷新开关（AppSettings 新键）。
【约束】MText/Table 序列化向后兼容（无域旧档不受影响）；域求值只读不改几何；崩溃安全
        （求值异常回落占位文本"###"）。
【验收】面积域随边界变更联动断言；明细栏数量列公式断言；旧档兼容；自测新增 ≥8 断言；零警告。
```

### 优先级排序（阻塞度 × 复用度 ÷ 风险）

| 序 | 差距 | 理由 |
|---|---|---|
| 1 | **D6 发布合规** | 商业化分发最后一公里，成本低、阻塞发货 |
| 2 | **D2 撤销差量化** | 性能最后硬洞；Modify 层范式现成，风险可控 |
| 3 | **D3 批量治理五件套** | 与已通的 DXF 导入形成"接图→修复→出图"闭环 |
| 4 | **D4 标注样式管理器** | 一图多标准刚性需求，DimStyle 结构现成 |
