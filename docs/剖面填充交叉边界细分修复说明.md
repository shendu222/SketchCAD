# 剖面填充·交叉/分隔边界细分修复说明

> 工程：`sketch-cad-cpp/`（C++17 / Qt6 / MinGW / CMake + Ninja）
> 涉及文件：`src/core/Section.cpp`、`tests/section_crossing_test.cpp`
> 关联需求：区域点选模式下面填充的两类缺陷修复

---

## 1. 背景与诉求

在「区域点选模式」已交付的基础上，实测发现两类不符合预期的剖面填充行为：

- **图 1（圆 + 四边形）**：只能点选并填充内部的圆，圆外（四边形内但圆以外的区域）无法被拾取与填充。
- **图 2（竖线分隔的矩形）**：整图只能作为一个整体填充，无法仅对竖线分隔出的**单侧**区域独立填充。

诉求：图 1 支持选择并填充圆形之外的任意区域；图 2 支持对竖线分隔出的单侧区域独立填充；修复后功能符合预期。

---

## 2. 根因分析

剖面填充管线为：`buildLoopsInternal`（端点容差贪心链式成环）→ `buildSectionLoopSet` → `pickRegionAt`（点选最内层环）→ `makeSectionChangeForPick`（生成 Hatch）。

原实现只对**互相不相交的自闭合图元**直接成环，缺少对「交叉线 / 分隔线把同一面切成多块」的平面细分处理。具体有三个失效点：

### 2.1 退化 bbox 导致宽相位漏交叉（核心根因）
`transverseHit` 与 `splitPolysAtIntersections` 用 `QRectF::intersects()` 做宽相位加速。但**零面积矩形**（`QRectF` 的 `intersects()` 对 width=0 或 height=0 的矩形返回 `false`）：
- 图 2 的竖直分隔线 bbox 宽为 0；
- 水平边界 bbox 高为 0。

→ 宽相位提前返回 `false`，竖线被判定为「不与矩形相交」，矩形走「直接成环」路径，于是整图只产出一个整矩形环，单侧无法独立成面。

### 2.2 悬挂尾（dangling tail）裹挟伪面
开放图元（如超出闭合边界的斜线尾端、超长竖线超出矩形上下端的端点）的端点在细分图中度为 1。面遍历（最小正向转角法则）会把这些度=1 的端点卷进一个**伪三角形面**，污染拾取。

### 2.3 网格对齐顶点合并漏合并
原顶点合并用 `llround(p.x/tol)` 网格键。当缺口（如 0.4 mm）跨网格边界时，两端点落入不同网格单元，不被合并，导致面遍历断开或 `RegionPickTest` 相关用例失败。

---

## 3. 修复方案

采用**平面细分（planar subdivision）**：所有边界段在相互 transverse 的交点处剪开，再从细分后的图做面遍历重建全部面，使交叉线 / 分隔线两侧各自成环。

三处配套修正：

1. **bbox 按容差外扩**：`bboxOf` 增加 `pad` 参数，宽相位相交判断前将两矩形各按 `tol` 外扩，覆盖零面积退化情形。
2. **容差内最近顶点合并**：`getV` 改为在 `tol` 内线性扫描已有顶点合并（取代网格键），缺口跨网格边界也能正确相邻合并。
3. **面遍历前悬挂尾修剪**：迭代删除所有度 `< 2` 的顶点及其关联边，剥除开放图元的悬挂尾，避免伪面。

> 旧路径保留：未被穿过的自闭合图元仍走「直接成环」，避免共边矩形被误合并。

## 4. 关键修改（`src/core/Section.cpp`）

| 位置 | 修改 |
|------|------|
| `splitPolysAtIntersections` (~644) | `bboxOf` 增加 `pad` 参数并按 `tol` 外扩；宽相位 `bi.intersects(bboxOf(polys[j].pts, tol))` |
| `buildLoopsSubdivided` (~700) | `bboxOf` 增加 `pad`；`transverseHit` 用 `bboxOf(a.pts, tol).intersects(bboxOf(b.pts, tol))`（~714） |
| `getV` lambda (~763) | 容差最近顶点合并：`vpts[i].distTo(p) <= tol` |
| 面遍历前 (~803) | 新增悬挂尾修剪 pass：迭代删度 `< 2` 顶点（含反向边同步删除），`trimChanged` 驱动 |
| `buildSectionLoopSet` (~1138) | 调用 `buildLoopsSubdivided(elems, tol, /*subdivide=*/true)`；点选链路 `pickRegionAt`（~1236）无需改动 |

## 6. 影响面与回归

- 仅影响剖面「区域点选」构建路径（`buildLoopsSubdivided` + `splitPolysAtIntersections`）；点选入口 `pickSectionRegionAt` / `makeSectionChangeForPick` 接口与签名不变。
- 旧行为保留：互不相交的自闭合图元仍直接成环，共边矩形等情形不受影响。
- 新增 `SectionCrossingTest` 已注册于 `CMakeLists.txt`（`add_executable` + `Qt6::Widgets` 链接 + `-Wall -Wextra`）。
