# C0层.dwg 渲染差异修复（第四轮：块引用悬空 + HATCH 丢弃）

> 日期：2026-10-19 ｜ 关联：第三轮（`--as r2004` 块几何保留、UTF-8 编码、TEXT 对齐、MULTILEADER）
> 现象：中文已正常，但三幅图框内图形大量缺失——表格上方图形未渲染、表格缺栏/格式错乱、彩色填充块消失。

## 定位方法

1. `dwg2dxf --as r2004` 桥输出 `C:/tmp/c0r2000/cmp_r2004/out2004.dxf`（1.30 MB，AC1018）。
2. 解析 DXF 拓扑：ENTITIES 段 981 实体（LINE 283 / TEXT 241 / MTEXT 162 / **INSERT 140** / MULTILEADER 16 / CIRCLE 16 / LWPOLYLINE 9 / ARC 2 / ATTRIB 58 / SEQEND 54）；BLOCKS 段 **38 个块定义、1418 实体**。
3. 块层级（关键）：三图框内容经**深层嵌套**——
   `机柜—C0层—带基础配线`(顶层) → `*U37` → `站机柜—C0层—空表格` → (`C0层—空表格` 大表 177 文本+70 线 / WAGO 系列 / `*U22` / 汇流排→`C0层-铜排` / 布置)；
   防雷 `*U28`/`*U29`（各 104 实体、含 HATCH 填充）/ 隔板 `*U20`/`*U21`/`*U23` 均为 `*U##` 匿名块变体。
4. 在 `SketchSelfTest` 加临时诊断块 ⑩：用程序真实 `fromDxf` + `expandBlockRef` 解析真档并输出程序视角统计，作为硬指标。

## 根因（两处）

### A. 匿名块 `*U##` 被一刀切丢弃（主因，整片图形消失）
`fromDxf` 收尾处原逻辑：块名以 `*` 开头一律 `continue`，不进块表。
注释理由只适用于 `*D`（标注图形块，几何已由 DIMENSION 组码重建）与 `*Model_Space`/`*Paper_Space`（ENTITIES 段已有同一批实体，进表即重复定义）。
但 LibreDWG 桥输出把**动态块的求值变体**也写成 `*U##`，且 INSERT 直接引用它们。本档实测 **10 种 ×24 处**引用指向 `*U##`——
于是整棵 `机柜→*U37→站机柜场景` 子树全部悬空，`evalDef` 对未定义块直接 `continue`，
**表格上方的机柜图形、防雷、隔板、铜排全部不渲染**，世界展开几何仅 4683（Python 全量 5482）。

### B. HATCH 环头 `72/73` 顺序未容错（彩色填充块消失）
`HATCH` 多段线边界环解析：`92(flag) → 73(is_closed) → 93(顶点数) → 顶点`。
LibreDWG r2004 **实测顺序为 `92 → 72(has-bulge) → 73 → 93`**，旧代码只 `if (73) ++k;`
遇见 72 不跳，于是 `93` 读不到、`vcount=0`、环为空、直接 `++fallback` → **7 个 HATCH 全部静默丢弃**。
`短路块` 的青色 SOLID 填充、`防雷` 的两处填充因此整个消失。

## 修复

### 修复 A — `src/core/CadFormats.cpp` 块表收尾
匿名块过滤改为**精确前缀**：仅跳过 `*Model_Space` / `*Paper_Space` / `*D`；`*U##` 等真实内容匿名块全部进块表。

### 修复 B — `src/core/CadFormats.cpp` HATCH 多段线环
`72/73` 均可省略且顺序不拘，改为循环容错跳过（至多 2 个），再读 `93`。

## 残留与说明

- `站机柜—C0层—布置` 块在 DWG/DXF 中**无实体定义**（LibreDWG 未写出其 BLOCK 段，仅保留块记录与 INSERT 引用；Python 全量参照渲染同样缺失，但画面已完整），属上游转换缺口，本档不影响三图框主体呈现。
- `防雷` HATCH 为 `带 bulge 的半圆环`（2 顶点 + 42 bulge），解析器未吸收 bulge，降级为**闭合折线（直线）**而非真实弧段——可见边界但形状略简化；如需精确半圆弧，需补 bulge→圆弧转换。
- `arcsDropped=36` 来自 LWPOLYLINE 带 bulge 段与个别 ARC 角度，属轻微保真损失，未纳入本轮。
