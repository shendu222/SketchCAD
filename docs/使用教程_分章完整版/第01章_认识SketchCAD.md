# 第01章 认识 SketchCAD

> *本章是全书的起点：认识 SketchCAD 的定位与本领，把它装进电脑，认得界面上每一块区域，再花 5 分钟画出一个带标注的圆——读完即可进入下一章，不需要记住任何细节。*

## 本章目标

- 了解 SketchCAD 的软件定位与七大特性，知道它能帮你做什么
- 学会在 Windows 上安装（含无人值守的静默安装）并启动软件
- 能够叫出界面各区域的名称与职责：菜单栏、工具栏、左侧 Dock、画布、参数输入条、状态栏、命令行
- 完成 5 分钟"尝鲜"演示：画一个圆、标注直径、保存文件
- 知道拿不准命令用法时，用 `help`（或 `F1`）随时自查

## 1.1 SketchCAD 是什么

### 1.1.1 一句话定位

SketchCAD（当前版本 1.1.0）是一款基于 Qt 6 的轻量级二维 CAD 软件，最初为航空 CAD 草图模块而构建，现已覆盖通用机械与建筑装修制图。它面向的场景不是"随手画个示意图"，而是**画符合国家标准的正式工程图**：线宽组别、线型、图框、尺寸注法、剖面填充、粗糙度符号均遵循 GB/T 系列标准（如 GB/T 4458、GB/T 14665），并支持一键切换到 ISO 标准。

> 💡 **给零基础读者**：CAD（Computer-Aided Design，计算机辅助设计）软件与画图软件的区别在于"精确"与"规范"——每个点都有确定的坐标，每条线都有确定的长度，整张图符合行业制图标准，可以直接交付加工或归档。

### 1.1.2 七大特性总览

| 特性 | 说明 |
|---|---|
| **轻量原生** | 纯 Qt Widgets 实现，零外部几何库——DXF / STEP / DWG 读写、剖面填充、约束求解均为自研 |
| **国标优先** | 线宽组别、线型、图框、尺寸注法、剖面、粗糙度遵循 GB/T 系列标准，支持 GB/ISO 一键切换 |
| **双模式交互** | 菜单、工具栏、鼠标直接绘制；同时支持底部命令行精确输入，如 `line 0,0 50,0` |
| **参数化模板** | 法兰盘、轴承座、箱体、法兰毂、飞机三面图、户型平面图 6 个模板，给定参数自动生成成套图面 |
| **命令生态** | 60+ 绘图与编辑命令，支持正交、栅格吸附、极轴追踪、对象捕捉、约束求解 |
| **扩展能力** | JavaScript 脚本、动作宏、CUI 别名（acad.pgp 兼容）、SDK 插件（C++ API）与 Windows COM 自动化 |
| **工程自证** | 403 项自测全部通过，`-Wall -Wextra` 编译 0 警告，附带性能基准与离屏渲染比对 |

前五项在本书第 1~6 部分逐章展开；扩展能力（脚本、宏、插件、COM）属于第 28~31 章的进阶内容，现在只需要知道"有这条路"即可。

### 1.1.3 数据模型一览

SketchCAD 的核心数据模型是一份统一的**图元**（Element）列表。图元指图纸中的一个基本图形对象——一条直线、一个圆、一段文字都是图元，共 12 类：直线、圆、圆弧、矩形、多边形、样条、椭圆、折线、文本、尺寸标注、剖面区域等。你在画布上看到的一切，本质上都是这份列表的可视化呈现。

文件格式支持四种：JSON（原生格式，完整往返）、DXF R12（与其他 CAD 交换）、DWG R12（原生二进制读写）、STEP（ISO 10303 标准格式，只写不读）。第02章会用到保存与导出，格式细节详见第26章。

## 1.2 安装与启动

### 1.2.1 环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（x64） |
| 运行库 | 以安装包提示为准（README 列出 MSVC 2022 Runtime） |
| 最低配置 | 4GB 内存，200MB 磁盘空间 |

### 1.2.2 安装：双击与静默

**普通安装**：下载最新安装包 `SketchCAD-<版本号>-Setup.exe`，双击运行，按向导提示完成即可。

**静默安装**（批量部署、无人工值守场景）：

```cmd
SketchCAD-<版本号>-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

静默卸载同样支持：

```cmd
SketchCAD-<版本号>-Setup.exe /VERYSILENT
```

### 1.2.3 启动与首次使用

安装完成后，双击桌面图标（或安装目录中的 `SketchCAD.exe`）启动。首次使用建议做两件事：

1. **确认绘图单位**：通过 `文件 › 单位与图纸界限` 打开设置对话框，机械制图选**毫米**。SketchCAD 内部几何一律以 mm 存储，单位设置只影响显示与输入口径，切换单位不会改动任何已有图形。
2. **认识 help**：在底部命令行输入 `help` 并回车，可以列出当前已注册的全部命令及参数；按 `F1`（菜单 `帮助 › 命令列表`）效果相同。这是你随身的命令字典，全书反复使用。

### 1.2.4 数据住在哪里

SketchCAD 不往安装目录写用户数据，运行数据统一放在：

```text
%LOCALAPPDATA%\SketchCAD
├── autosave\   自动保存快照（崩溃恢复依据）
├── logs\       运行日志（滚动保留）
└── crashes\    崩溃转储文件
```

COM 自动化的注册信息位于注册表 `HKCU\Software\SketchCAD`。自动保存与崩溃恢复的完整机制见第04章与附录B。

### 1.3.1 菜单栏

顶部菜单自左向右依次为：**文件、打印、追踪、编辑、绘图、测量查询、视图、脚本、界面、插件、帮助**。日常绘图最常用的是三个：

- **文件**：新建（`Ctrl+N`）、打开、保存（`Ctrl+S`）、导出 DXF（`Ctrl+E`）、绘图比例、单位与图纸界限等；
- **绘图**：全部图元绘制命令与制图模板入口，按直线、圆、弧、多边形、样条、椭圆、折线分子菜单组织；
- **编辑**：修改（移动/旋转/镜像/阵列/修剪等）与选择两大子菜单。

其余菜单各有分工：**追踪**集中了正交、极轴、对象捕捉等精确绘图开关（第03章主角）；**视图**管缩放平移与面板显隐；**脚本/界面/插件**属于二次开发篇（第28~31章）。

### 1.3.2 工具栏

菜单栏下方有两排工具栏：**草图工具栏**（选择、基本图元、圆、弧、折线等绘制入口）与**样式视图工具栏**（删除、线宽、线型、标准切换、连续线等）。工具栏是"鼠标党"的主战场，与菜单、命令行三者在功能上完全等价——同一个功能至少有两条路可走，这是贯穿全书的原则。

### 1.3.3 左侧与右侧 Dock 面板

画布左侧的 Dock 区域可以切换多种面板：**图层面板**（管理 GB/T 14665 规定的 12 个标准图层）、**图元面板**（浏览图元列表）、**属性面板**（查看/编辑选中图元参数）、**BOM 树**（明细栏结构）、**日志**与**命令行**。各面板的显隐通过 `视图 › 面板` 控制。图层面板的详细用法见第16章，这里先记住位置即可。

### 1.3.4 画布：网格、坐标轴与鼠标手势

中央最大的区域是**画布**——所有图元的家。画布上有两样常驻的东西：

- **坐标网格**：背景网格辅助定位，按 `F7` 开关；
- **坐标轴**：X 轴向右、Y 轴向上的世界坐标指示。

> ⚠️ 坐标轴是**常显**的，菜单中没有开关可以隐藏它（这一点与栅格不同）。坐标轴与提示文字绘制在覆盖层上，不随视图缩放而变化。

鼠标在画布上的两个基本手势现在就可以试：**按住右键拖拽 = 平移视图**，**滚动滚轮 = 以光标为中心缩放**。视图操作的完整清单（含快捷键）见第04章。

### 1.3.5 参数输入条

工具栏下方、画布上方有一条**参数输入条**，含四个输入框：**角度、长度、间隔、条数**，外加一个线型下拉框。它跟随当前绘制命令自动启停——画直线时用"角度+长度"，画圆时"长度"自动变为"半径"，画正多边形时"条数"变为"边数"。它是介于"纯鼠标目测"与"纯命令行"之间的第三条精确输入路径，第03章会专门练习。

### 1.3.6 状态栏与命令行

窗口底部左侧是**状态栏**：实时显示光标的世界坐标读数、一组精绘开关按钮（正交/极轴/捕捉/追踪/线宽，单击即可切换），以及"上次自动保存"时间按钮（点击可立即手动保存一次快照）。

底部右侧的文本输入框是**命令行**——SketchCAD 的精确控制台。它接受形如 `命令名 参数1 参数2 ...` 的指令，坐标统一写成 `x,y`（逗号分隔，默认单位 mm）。例如：

```text
line 0,0 50,0
```

画出一条从 (0,0) 到 (50,0) 的水平线段。命令行还带自动补全与动态提示，输入几个字母就能看到候选命令。命令行的语法总则详见第02章。

## 1.4 两种操作方式：点鼠标，或敲命令

SketchCAD 的每一项绘图功能都有 **GUI（菜单/工具栏/快捷键）** 与 **命令行** 两种触发方式。以画一个圆心在 (100,100)、半径 50 的圆为例：

- **GUI**：菜单 `绘图 › 圆 › circle（圆心+半径）`，在画布上点一下圆心，再移动鼠标到合适半径单击；
- **命令行**：

```text
circle_cr 100,100 50
```

两条路产出完全相同的图元。一般建议：**探索功能时用 GUI（看得见、点得着），要精确时用命令行（数字直达、可复现）**。本教程的示例会尽量两种都给。

## 1.5 五分钟尝鲜：画一个圆并标注

目标：画一个 Ø100 的圆，标上直径尺寸，保存。不求理解每一步，只求"原来如此"。

步骤 1：启动 SketchCAD，按 `Ctrl+N` 新建图纸，幅面选 **A4**、比例 **1:1**、投影角选**第一角**，确定。

步骤 2：画圆。在命令行输入：

```text
circle_cr 100,100 50
```

回车后画布上出现一个圆心在 (100,100)、半径 50 的圆。（GUI 等效路径：`绘图 › 圆 › circle（圆心+半径）`。）

步骤 3：标直径。按 `Shift+I`（菜单 `绘图 › 尺寸标注 › 直径`），把光标移近圆——圆被高亮时单击选中，再移动鼠标把标注线拉到圆外合适位置单击放置。图面上出现"Ø100"字样的直径标注。

步骤 4：按 `Ctrl+0`（适配窗口），所有图元自动充满工作区，方便检查整体效果。

步骤 5：按 `Ctrl+S` 保存为 `first_circle.json`。

> ✅ **判定成功**：画布上有 1 个圆和 1 个直径标注；`Ctrl+0` 后图形充满视口；`first_circle.json` 文件已生成。如果你还顺手按了 `F1` 看了一眼命令列表，本章任务就超额完成了。

做完这个例子，你其实已经走完了"新建 → 绘制 → 标注 → 保存"的微缩流程。第02章会把这条流程扩展成一张完整的草图。

## 练习

1. 对照 1.1.2 的特性表，说出你最期待的两项能力，并在 `help` 输出里各找一个与它相关的命令名（能"望文生义"即可）。
2. 打开 `视图 › 面板` 子菜单，把"日志"面板显示出来再隐藏，观察左侧 Dock 的变化；再按 `F7` 切换栅格显示，对比栅格与坐标轴哪个能关、哪个不能关。
3. 实操题：新建 A4 图纸，用命令行画圆心 (150,100)、半径 30 的圆，再用 `Shift+I` 标注直径，最后保存为 `ex01.json`。写出你输入的命令。
4. 在资源管理器地址栏输入 `%LOCALAPPDATA%\SketchCAD` 回车，看看这个目录下有哪些子目录，分别对应 1.2.4 表中的哪一项。
5. 用滚轮缩放和右键拖拽平移浏览 1.5 节画出的图，体会两种手势的区别；然后按 `Ctrl+0` 回到全局视图。

## 本章小结

| 要点 | 内容 |
|---|---|
| 定位 | 基于 Qt 6 的轻量 2D CAD，国标优先（GB/T 系列标准），机械+航空为主 |
| 七大特性 | 轻量原生 / 国标优先 / 双模式交互 / 参数化模板 / 命令生态 / 扩展能力 / 工程自证 |
| 安装 | 双击安装包，或 `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART` 静默安装 |
| 数据目录 | `%LOCALAPPDATA%\SketchCAD`（autosave / logs / crashes） |
| 界面七区 | 菜单栏、工具栏、参数输入条、左侧 Dock、画布、状态栏、命令行 |
| 画布手势 | 右键拖拽平移、滚轮缩放；`F7` 栅格开关；坐标轴常显无开关 |
| 随身字典 | `help` / `F1` 列出全部命令 |
| 尝鲜命令 | `circle_cr 100,100 50`、`Shift+I` 直径标注、`Ctrl+0` 适配、`Ctrl+S` 保存 |

界面认熟了，圆也画出来了——下一章我们正式开始画图：从新建图纸的三个参数讲起，学会 `line`、`rect`、`circle_cr` 三板斧，走完"绘制 → 纠错 → 保存 → 导出"的完整闭环，并完成你的第一张工程草图。
