# 第02章 绘制第一张图

> 从新建图纸到保存导出，本章带你走完 SketchCAD 绘图的完整闭环——并完成你的第一张工程草图。

## 本章目标

- 学会新建图纸并理解幅面、比例、投影角三个参数的含义
- 掌握 `line`、`circle_cr`、`rect` 三个最基础命令的 GUI 与命令行两种用法
- 理解 SketchCAD 命令行的基本语法（命令名 + 参数、`x,y` 坐标写法）
- 学会删除、撤销与重做，养成"随手可逆"的绘图习惯
- 完成一张**平键垫片草图**并保存为 JSON、导出为 DXF

## 2.1 新建图纸

### 2.1.1 幅面、比例与投影角

启动 SketchCAD 后，按 `Ctrl+N`（或菜单 `文件 › 新建`）打开新建图纸对话框。对话框里有三组关键参数：

| 参数 | 含义 | 建议初学取值 |
|---|---|---|
| **幅面** | 图纸大小，GB/T 14689 规定的 A0~A5 系列。A4 = 210×297mm | A4 |
| **比例** | 图上尺寸与实物尺寸之比（GB/T 14690 标准系列）。1:1 表示按实际尺寸绘制 | 1:1 |
| **投影角** | 第一角投影（GB 传统，中国/欧洲常用）或第三角投影（ISO，美国常用） | 第一角 |

> 💡 **给零基础读者**：可以先把这些参数理解为"纸的大小"和"画图的缩放倍数"。1:1 意味着 100mm 长的零件在图上就画 100 个绘图单位，这是最不容易出错的选择。

步骤 1：按 `Ctrl+N` → 幅面选 **A4**、比例 **1:1**、投影角 **第一角** → 确定。画布上会出现 A4 图框与标题栏。

### 2.1.2 认识命令行

窗口底部有一个文本输入框，这就是**命令行**——SketchCAD 的"精确控制台"。它接受形如：

```text
命令名 参数1 参数2 ...
```

的指令。坐标统一写成 `x,y`（逗号分隔，不带单位，默认 mm）。例如：

```text
line 0,0 50,0
```

表示画一条从点 (0,0) 到点 (50,0) 的直线。

> 💡 输入 `help` 并回车，可以列出当前已注册的全部命令及其参数——这是本教程之外最重要的"随身字典"，按 `F1`（菜单 `帮助 › 命令列表`）也能随时查看。

## 2.2 三个最基础的绘图命令

### 2.2.1 直线 line

**GUI 方式**：菜单 `绘图 › 直线 › line（两点线）`，在画布上先点一下确定起点，再点一下确定终点。

**命令行方式**（推荐，精确）：

```text
line 0,0 100,0
```

画出一条长 100 的水平线段。试着自己输入几条：

```text
line 0,0 100,0        ← 底边
line 0,0 0,60         ← 左边
line 100,0 100,60     ← 右边
line 0,60 100,60      ← 顶边
```

四条命令画出一个 100×60 的矩形轮廓。这条路径在下一节会被 `rect` 一条命令取代——但理解"一切图形都由基本图元拼成"这件事，比省事更重要。

### 2.2.2 矩形 rect

```text
rect 0,0 100,60
```

两个参数分别是**左下角**和**右上角**坐标，一步画出刚才的四条边（作为一个复合图元，选中时四条边一起动）。

GUI 方式：菜单 `绘图 › 多边形 › rect`，依次点击两个对角点。

### 2.2.3 圆 circle_cr

`circle_cr` = **c**enter + **r**adius（圆心 + 半径）：

```text
circle_cr 50,30 15
```

在 (50,30) 处画一个半径 15 的圆。GUI 方式：菜单 `绘图 › 圆 › circle（圆心+半径）`，先点圆心，再移动鼠标输入半径。

## 2.3 改错了怎么办：删除、撤销与重做

- **删除**：选中图元（单击），按 `Del`。
- **撤销**：`Ctrl+Z`，或命令行输入 `undo`。
- **重做**：`Ctrl+Y`，或命令行输入 `redo`。

SketchCAD 的撤销/重做基于**快照栈**（Memento，含图元 + ID + 比例 + 图层），每一步都可逆。放心试错，是学 CAD 最快的方式。

> ⚠️ 撤销对**所有**绘图与编辑操作有效，但视图缩放、平移这类"看图操作"不在撤销栈里——它们不改变图纸数据。

## 2.4 动手案例：平键垫片草图

目标：画一个 100×60 的矩形垫片，中心开 Ø30 的孔，再画两条穿过中心的十字中心线。完成后效果：

```text
      ┌────────────────────────┐
      │          ┆             │
      │          ┆     ◯      │   ◯ = Ø30 中心孔
      │     ─────┼─────        │   ┆/─ = 中心线（点画线）
      │          ┆             │
      └────────────────────────┘
```

步骤 1：`Ctrl+N` 新建 A4、1:1 图纸。

步骤 2：画外轮廓：

```text
rect 0,0 100,60
```

步骤 3：画中心孔（圆心即矩形中心 (50,30)，Ø30 即半径 15）：

```text
circle_cr 50,30 15
```

步骤 4：画两条中心线，略微超出轮廓（各超出 5mm）：

```text
line -5,30 105,30
line 50,-5 50,65
```

步骤 5：按 `Ctrl+0`（适配窗口），所有图元精确充满工作区，检查整体效果。

步骤 6：保存。`Ctrl+S` 存为 `washer.json`（原生格式，含全部图元与样式，下次可完整打开继续编辑）。

步骤 7：导出。`Ctrl+E` 导出为 `washer.dxf`（R12 格式，可被 AutoCAD 等第三方 CAD 打开）。

> ✅ **判定成功**：画布上有 1 个矩形、1 个圆、2 条中心线；`Ctrl+0` 后整体充满视口；导出的 `washer.dxf` 能在其他 CAD 软件中打开且几何一致。

## 2.5 保存与导出的格式选择

| 格式 | 快捷键 | 用途 |
|---|---|---|
| `.json` | `Ctrl+S` | **原生格式**，完整往返，日常编辑首选 |
| `.dxf` | `Ctrl+E` | 与其他 CAD 交换（R12 兼容） |
| `.dwg` | — | 原生 R12 二进制读写，详见第26章 |
| `.step` | — | ISO 10303 标准格式，**只写不读** |

格式细节与选型决策详见第26章。

## 练习

1. 用 `rect` 和 `circle_cr` 画一个 160×90 的矩形板，中心开 Ø40 圆，四角各开一个 Ø10 的角孔（角孔圆心距两边各 15）。
2. 命令行输入 `help`，找到本章没有讲过的两个命令，猜猜它们的用途。
3. 画错是一种常态：故意画一条错误直线，分别用 `Del` 和 `Ctrl+Z` 两种方式处理，观察两者适用场景的差别。
4. 把练习 1 的成果分别保存为 `.json` 和 `.dxf`，用记事本打开 `.json` 看看图元是如何存储的（能认出坐标数字就算合格）。

## 本章小结

| 命令/操作 | 用途 |
|---|---|
| `Ctrl+N` | 新建图纸（幅面/比例/投影角） |
| `line x1,y1 x2,y2` | 两点画线 |
| `rect x1,y1 x2,y2` | 画矩形 |
| `circle_cr cx,cy r` | 圆心+半径画圆 |
| `Del` / `Ctrl+Z` / `Ctrl+Y` | 删除 / 撤销 / 重做 |
| `Ctrl+0` | 适配窗口 |
| `Ctrl+S` / `Ctrl+E` | 保存 JSON / 导出 DXF |
| `help` / `F1` | 列出全部命令 |

你已经掌握了"输入坐标 → 生成图元 → 纠错 → 保存"的最小闭环。但真实的工程图不允许"差不多"——下一章我们把鼠标放一边，学习让每个点都精确落位的帮手：坐标系统、正交、栅格与对象捕捉。
