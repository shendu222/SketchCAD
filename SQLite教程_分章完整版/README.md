# SQLite 快速上手教程（C/C++ 篇）

本书是一本面向 C/C++ 开发者的 SQLite 快速上手教程，目标是用最短的路径让你从零开始：

- 会用 `sqlite3` 命令行工具建库、建表、跑 SQL；
- 掌握日常开发最常用的 SQL（增删改查）；
- 能在 C 和 C++ 程序中连接 SQLite 数据库，完成增删改查与事务；
- 懂得参数绑定、错误处理这些"不踩坑"的关键实践。

本书定位是**快速上手**，不追求 API 百科式覆盖——自定义函数、虚拟表、备份 API 等高级主题不在本书范围内，学完本书后可自行查阅 [SQLite 官方文档](https://www.sqlite.org/c3ref/intro.html) 深入。

## 环境要求

- **操作系统**：Windows / Linux / macOS 均可，本书示例以 Windows 为主，Linux/macOS 差异之处会注明。
- **编译器**：任一 C/C++ 编译器（MSVC、MinGW-w64 gcc、clang 均可）。
- **SQLite 源码**只需从官网下载一个约 2.5 MB 的"合并源文件"包（amalgamation），第 1 章手把手教你下载与编译。
- **构建工具**：第 4 章给出直接命令行编译与 CMake 两种方式，二选一即可。

## 体例说明

每章统一采用以下结构：

- **本章目标**：学完你能做到什么；
- **正文**：概念讲解 + 手把手示例（含完整可运行代码）；
- **动手练习**：巩固所学的小任务；
- **参考答案**：以折叠块（`<details>`）形式给出，先自己动手再展开；
- **本章小结**：一屏看完的重点回顾；
- **下一章预告**：承上启下。

代码约定：C 语言章节代码兼容 C99，C++ 章节使用 C++11 及以上；所有示例围绕一个"通讯录"数据库 `contacts.db` 展开，前后连贯。

## 如何使用本书

1. 按章节顺序阅读，第 1~3 章是工具与 SQL 基础，第 4~8 章是 C/C++ 编程；
2. 每章的示例务必亲手敲一遍、跑一遍——SQLite 零部署成本的特性决定了"边学边跑"几乎无门槛；
3. 练习先自己做，卡住 10 分钟以上再看折叠答案；
4. 读完第 8 章的综合实战后，建议把你手头一个真实小需求（如配置存储、日志记录）迁移到 SQLite 练手。
